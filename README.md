## 📋 Sobre

Aplicação web do Zentro com interface responsiva e moderna, consumindo a API REST para gerenciamento de dados.

## 🚀 Como Rodar

**Pré-requisitos:** Node.js 18+ e [API do Zentro](https://github.com/LuanMSouza/zentro-back) rodando.

```bash
git clone https://github.com/LuanMSouza/zentro-front
cd zentro-front
npm install
cp .env.example .env
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).
